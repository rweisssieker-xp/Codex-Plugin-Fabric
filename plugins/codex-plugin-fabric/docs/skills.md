# Bundled Skills

The plugin includes specialized Codex skills for common Microsoft Fabric operator workflows.

## `fabric-operator`

General Fabric operating workflow for inventory, deployment preflight, guarded execution, diagnostics, and governance.

## `fabric-change-assurance`

Change-board workflow for assurance reports, scores, approval evidence, and HTML review output.

## `fabric-policy-governor`

Policy simulation and tightening workflow for guardrail review without writing policy files.

## `fabric-environment-drift`

Environment fingerprinting and drift review workflow for dev, test, and production comparisons.

## `fabric-incident-commander`

Incident timeline, root-cause ranking, and executive/operator brief workflow.

## `fabric-release-manager`

Guided release playbook workflow for preflight, approval, step validation, guarded execution, and final evidence.

## `fabric-governance-board`

Release-gate workflow for approval-chain evidence, blast radius, sensitivity review, capacity/cost risk, and go/conditional-go/no-go decisions.

## `fabric-compliance-officer`

Compliance workflow for checksum-backed evidence bundles, audit anomaly detection, least-privilege role review, policy exception evaluation, and release risk matrices.

## `fabric-resilience-architect`

Release-resilience workflow for what-if deployment simulation, rollback readiness, ownership coverage, data contract review, tenant posture, and operational SLO evidence.

## `fabric-executive-control`

Executive control workflow for workspace criticality, change freeze windows, access recertification, management release briefs, and operator action queues.

## `fabric-value-and-maturity`

Portfolio workflow for business impact, dependency bottlenecks, release calendar collisions, recovery drills, and control maturity scoring.

## Workflow Recipe Tools

Use `fabric_list_workflow_recipes`, `fabric_get_workflow_recipe`, and `fabric_generate_workflow_prompt` to discover and reuse these workflows programmatically.
