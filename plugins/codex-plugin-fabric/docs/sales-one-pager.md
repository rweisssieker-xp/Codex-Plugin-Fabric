# Sales One-Pager

## Microsoft Fabric Control

The safety-first Microsoft Fabric operator plugin for Codex.

## Problem

Fabric operations often require switching between portals, scripts, logs, IDs, deployment stages, and permission models. Teams need faster ways to inspect and operate Fabric, but production automation without guardrails can create expensive mistakes.

## Solution

Microsoft Fabric Control gives Codex a local MCP control plane for Fabric. It lets teams inspect workspaces, preflight deployments, run supported jobs, monitor operations, diagnose failures, generate runbooks, and enforce production safety.

## Best-Fit Teams

- DataOps teams managing Fabric environments
- BI and analytics engineering teams
- Platform teams standardizing Fabric delivery
- DevOps teams supporting Fabric deployment pipelines
- Organizations with Dev/Test/Prod Fabric workspaces

## Key Outcomes

- Faster workspace and deployment inspection
- Safer production deployments
- Better failure triage
- Clearer audit trail for mutating actions
- Reduced dependency on manual portal workflows

## Top Differentiators

- Codex-native MCP toolset
- Production guardrails by default
- Deployment preflight and risk scoring
- Long-running operation polling
- Local audit logs with secret redaction
- Dependency graph and blast-radius intelligence
- No destructive V1 operations

## Buyer Message

Use Codex to operate Microsoft Fabric with the speed of natural language and the discipline of production controls.

## Technical Message

The plugin exposes typed MCP tools backed by Fabric REST APIs, MSAL authentication, target-binding guardrails, redacted JSONL audit logs, local environment memory, and structured diagnostics.

## Competitive Angle

Generic scripts automate actions. Microsoft Fabric Control operationalizes them with context, safety, diagnostics, and Codex-native composability.
