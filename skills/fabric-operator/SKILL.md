# Microsoft Fabric Operator

This root skill shim is provided for marketplace scanners that validate the repository root as the plugin artifact. The implementation and full documentation live in `plugins/codex-plugin-fabric/skills/fabric-operator/SKILL.md`.

Use the Microsoft Fabric Control MCP server to inspect workspaces, run deployment preflight, execute guarded Fabric operations, check Git status, compare definitions, inspect connections/gateways/capacities, diagnose failures, and review audit logs.
